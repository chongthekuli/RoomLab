# RoomLAB Regression Index

**What this is.** One row per shipped code-bug. Each row links the user-visible symptom to the guarding test that would have caught it. If a fix shipped without a test, the row is `UNGUARDED` and routes to Sam (qa-engineer) for a spec.
**Who maintains it.** Theo Halvorsen (regression-curator). Same-PR rule: every bug-fix commit must add or extend a regression test in the SAME commit; no exceptions, no "next sprint."
**Legend.**  `GUARDED` = a real test asserts the bug stays fixed. `UNGUARDED` = fix shipped without a test; needs a spec. `OBSOLETE` = the code path that hosted the bug has been removed (must link the removing commit).
**How to add a row.** Append the next sequential `RL-NNN`. Fill every column. Use a real commit-sha (short, 7 chars). For `GUARDED` rows, give file + test name verbatim (e.g. `tests/spl.test.mjs :: "Back-pivot: adjacent cabinets share their back edge"`). For `UNGUARDED` rows, leave the test column empty and add a TODO note.

> **Scope note.** This index tracks **code bugs** only. Process rules captured in `feedback_*.md` — `feedback_visual_physics_local_first`, `feedback_visual_physics_workflow`, `feedback_uat_gate`, `feedback_verify_deploys`, `feedback_powershell_utf8_corruption`, `feedback_render_path_diff_first`, `feedback_style_match_audit_first`, `feedback_askuserquestion_tool_syntax`, `feedback_terms_modal_legal_owner`, `feedback_elena_arena_rules`, `feedback_line_array_physics` (validation rules, not a bug) — are NOT bugs and do not belong here. They live in `CLAUDE.md` §3 / §5 as workflow invariants.

## Process notes

- The five `UNGUARDED` rows above are the May 2026 baseline (Hannes audit, 2026-05-18). Same-PR compliance was ~12% before this index existed; the rule cannot be enforced without a written canon.
- The four high-friction bugs called out in the regression-curator persona prompt (speaker aim arrows, walk-collision through open walls, wall-overlap split, shared-wall click) are NOT yet in this index — they shipped before the index existed and need a backfill pass. Treat as RL-017+ pending commit-sha verification.
- Hooks proposed in `CLAUDE.md` §7 (same-PR test reminder, cache-bump check) are the mechanical enforcement layer. Until they ship, enforcement is by code review.
